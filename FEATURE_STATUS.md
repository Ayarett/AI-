# Статус реализации функций (FEATURE_STATUS)

Честный технический аудит всех подсистем платформы **AI Ұстаз** (автор проекта: **Бахыт Нуршат**).

| Функция / модуль | Статус | Зависимости / ограничения |
| --- | --- | --- |
| Открытый доступ без регистрации + аккаунты | **Работает** | Все разделы ученика и учителя открываются сразу без входа (`localStorage` для гостя); личный кабинет с серверной аутентификацией (`scrypt` + соль) — по желанию. |
| Смена и восстановление доступа | **Работает** | Секретная фраза хэшируется; смена аккаунта, переключение роли (Ученик/Учитель) и удаление профиля работают через серверный API. |
| Изоляция данных пользователей | **Работает** | Для авторизованных пользователей хранится отдельный `UserWorkspaceData` в `/data/ai-ustaz-db.json`; для гостей — локальный профиль и рабочая область. |
| Двуязычность интерфейса (`kk` / `ru`) | **Работает** | Переключение мгновенно сохраняется в профиле; отдельная настройка языка обучения школы (`kk` / `ru`). |
| Учебная база 1–11 классов РК | **Работает** | Ступени 1–4, 5–6, 7, 8–9 (единое направление), 10–11 (с выбором профиля), 5 нормативных ссылок, исключения (`Дене шынықтыру`, `Самопознание`, `AI Teacher`). |
| AI-учитель (диалог + «Другой вопрос») | **Работает при наличии API-ключа** | Открыт всем (включая гостей через `optionalAuth` и историю диалога). Использует серверный `@google/genai` (`gemini-4-hydrogen` + резервные модели при пиковой нагрузке `503`). |
| Диагностика знаний и пересдача | **Работает** | Доступна без регистрации (`optionalAuth`). Серверная проверка ответов, 3 категории, свежие задания при пересдаче; персональный ИИ-план через `GEMINI_API_KEY`. |
| Расписание, смены и задачи (ДЗ/СОР/СОЧ) | **Работает** | Полный CRUD уроков и задач (для аккаунтов — на сервере, для гостей — локально), 40-мин уроки и перемены 5/10/10. |
| Браузерные уведомления по расписанию | **Ограничено средой браузера** | Работает через Web `Notification` API только при поддержке браузером и явном согласии пользователя; фоновые push-уведомления при закрытой вкладке не используются. |
| Мой прогресс | **Работает** | Личный график и история попыток; рейтинги и сравнения с другими учениками отсутствуют намеренно. |
| Кабинет учителя (10 инструментов) | **Работает при наличии API-ключа** | Открыт всем без обязательного входа (`optionalAuth`). Презентации со слайдами (редактирование, сортировка, HTML-экспорт), КСП, тесты с ключами, рабочие листы, рубрики и др. |
| Интерактивный 3D-учитель | **Работает** | Three.js персонажи (`Мұғалім әйел` и `Мұғалім ер`, 3 образа, движение рук и отслеживание взгляда/курсора), корректная очистка WebGL. |
| Тёмная / светлая тема и мобильная адаптация | **Работает** | Переключение темы, адаптивная сетка и нижняя мобильная панель. |
