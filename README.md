# AI Ұстаз

Образовательная платформа и цифровой ИИ-учитель для школьников 1–11 классов и педагогов общеобразовательных школ Республики Казахстан.

**Автор и создатель проекта:** Бахыт Нуршат.

---

## Возможности платформы

- **Два языка интерфейса и разделение с языком обучения:**
  - Язык интерфейса: `Қазақша` / `Русский`.
  - Язык обучения школы (отдельная настройка): `Қазақ тілінде оқытатын мектеп` / `Русский язык обучения`.
- **Кабинет ученика (1–11 классы):**
  - `Главная`: сводка дня, активные задания, контрольные, история диагностик, интерактивный 3D-учитель.
  - `Предметы`: официальная сетка предметов 1–11 классов РК, цели обучения, ожидаемые результаты, уровни сложности, профильные акценты (для 5–9 как акцент, для 10–11 как гуманитарное или физико-математическое направление).
  - `AI-учитель`: многоходовый контекстный диалог на сервере с кнопкой «Басқа сұрақ бойынша» / «Другой вопрос».
  - `Диагностика знаний`: тестирование по теме, разделу или классу, серверная проверка ответов, распределение тем на `Жақсы меңгерілген`, `Қайталау қажет`, `Қосымша дайындық қажет`, генерация личного плана обучения и повторное тестирование на свежих вопросах (`variantGroup: 1 | 2`).
  - `Моё расписание`: конструктор звонков (`08:00`, `11:30`, `14:00`, `15:30` или своё время, 40 мин урок, перемены 5/10/10 мин), расписание уроков, домашние задания и контрольные работы, опциональные уведомления через браузерный Notification API.
  - `Мой прогресс`: персональная динамика без токсичных рейтингов и сравнения с одноклассниками.
  - `Настройки`: язык интерфейса, язык обучения, 3D-персонаж (мужской/женский, 3 варианта одежды), смена и удаление аккаунта.
- **Кабинет учителя (10 инструментов):**
  - Презентации со слайдами (редактирование, перестановка слайдов, экспорт в HTML), поурочные планы (ҚМЖ), тесты с ключами ответов, самостоятельные и контрольные работы, рабочие листы, критерии оценивания (рубрики), дифференцированные задания, вопросы к уроку, краткие конспекты.
  - Просмотр всей учебной базы 1–11 классов.
- **Интерактивный 3D-учитель:** композитный Three.js персонаж с выбором образа и живой анимацией состояний (`greeting`, `explaining`, `happy`, `thinking`, `calm`).

## Технологический стек

- **Frontend:** React 19, TypeScript, Tailwind CSS v4, Lucide Icons, Three.js (`three`).
- **Backend:** Node.js + Express (`server.ts`), Vite middleware в dev-режиме, статическая раздача `dist/` в production.
- **ИИ-интеграция:** `@google/genai` (серверные запросы к Gemini API; ключ никогда не передаётся в браузер).
- **Хранение данных:** Атомарное файловое хранилище `/data/ai-ustaz-db.json` (изоляция рабочего пространства для каждого пользователя, пароли и секретные фразы хэшируются через `scrypt` с солью).

## Переменные окружения

Определены в `.env.example`:

- `GEMINI_API_KEY` — серверный ключ Gemini API (необходим для работы AI-учителя, генерации персонального плана после диагностики и всех 10 инструментов кабинета учителя). Без ключа соответствующие API возвращают `503` с честным предупреждением в интерфейсе.
- `SESSION_SECRET` — (опционально) секрет для HMAC-подписи токенов сессии. Если не задан, генерируется и сохраняется локально.
- `PORT` — порт сервера (по умолчанию `3000`).

## Структура проекта

- `server.ts` — Express-сервер, маршруты аутентификации, диагностик, расписания, AI-учителя и студии учителя.
- `server/storage.ts` — атомарный JSON-слой хранения, хэширование паролей (`scrypt`), HMAC-сессии и изоляция данных пользователей.
- `src/types/platform.ts` — единые TypeScript-типы платформы.
- `src/data/curriculum.ts` — структурированная учебная база РК для 1–11 классов.
- `src/data/diagnosticsBank.ts` — банк диагностических заданий (включая группы вариантов для повторной проверки).
- `src/components/` — модули интерфейса (кабинеты ученика и учителя, 3D-учитель, SVG-иллюстрации предметов).
- `src/i18n/translations.ts` — двуязычный словарь (`kk` / `ru`).

## Как расширять учебную базу и банк заданий

1. **Добавление тем в `src/data/curriculum.ts`:**
   Добавьте новый объект `CurriculumTopic` в соответствующий `sectionsByGradeRange` нужного предмета. Укажите `learningObjective` (`kk`/`ru`), `expectedResult`, `difficulty`, `exerciseTypes`, `prerequisites`, `officialSource` и статус `VERIFIED` или `NEEDS_REVIEW`.
2. **Добавление вопросов в `src/data/diagnosticsBank.ts`:**
   Добавьте объект `DiagnosticQuestion` с `subjectId`, `grade`, `topicId`, `variantGroup` (`1` или `2`), формулировкой вопроса и вариантами ответа на `kk` и `ru`, а также `correctIndex` или `expectedAnswer` и `explanation`. Сервер автоматически использует эти данные при проверке попыток.
